# Investigación - Integrante C (Tienda IA)

## Introducción a la Integración de APIs con FastAPI
FastAPI es un framework web moderno y de alto rendimiento para construir APIs con Python, basado en anotaciones de tipos estándar de Python. Permite una documentación automática interactiva mediante Swagger UI y ReDoc.

## Manejo de Dependencias y Entornos Virtuales
- Uso de entornos virtuales (`.venv`) para aislar las librerías del proyecto.
- Resolución de conflictos de compilación en Windows mediante la selección de paquetes precompilados y exclusión de dependencias opcionales complejas.
